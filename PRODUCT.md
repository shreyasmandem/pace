# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React + TypeScript + Vite, client-only SPA (react-router-dom for routing, zustand for state). No backend — confirmed with the user: progress/notes/bookmarks are localStorage-only with export/import backup, not accounts+sync. This was a direct decision made with the user during planning (see the approved plan at `C:\Users\shrey\.claude\plans\floating-dancing-star.md`), not an unconfirmed inference.

## Users

Self-directed learners preparing for software engineering interviews — the same audience that currently works through Striver's A2Z DSA Sheet (takeuforward.org) and/or NeetCode's problem lists. They're doing structured, long-horizon practice (weeks to months), tracking which problems they've solved, revisiting topics, and want video explanations and their own notes attached to problems, not just a bare checklist.

## Product Purpose

Pace is a free, all-in-one DSA interview-prep tracker. It replicates and improves on takeUforward's A2Z DSA Sheet, plus NeetCode 150, NeetCode 250, and Blind 75, in a single app: real links to LeetCode/GfG/Code360/YouTube/NeetCode per problem, per-topic video lectures, per-problem personal notes, bookmarking, and progress tracking — for free, where the original TUF experience gates notes/videos behind login and a paid plan.

## Positioning

Existing trackers (Codolio, the takeUforward sheet itself, various open-source clones) either paywall/login-gate the useful parts (notes, videos) or are bare checklists with no real content attached. Pace's mechanism: every problem across all four tracks carries real, verified links (not placeholders) — LeetCode, GfG, Code360, the actual takeUforward YouTube lecture matched per-problem/topic, or NeetCode's own solution video — plus original topic-level "intuition" notes, entirely for free with no login wall.

## Operating Context

Single-page app, used in a browser (desktop primarily, mobile as a secondary but real use case per the user). A user picks a track (A2Z / NC150 / NC250 / Blind75), works through topic-grouped problem lists over many sessions, checks off problems, writes personal notes, bookmarks problems to revisit, and checks aggregate progress/streaks. No multi-user, no collaboration, no server round-trips beyond loading the static app and its bundled data.

## Capabilities and Constraints

- Four tracks, each a normalized list of topic groups → problems, generated by a build-time data pipeline (`data-pipeline/`) from third-party source data (Striver's A2Z sheet data, NeetCode 150/250 exports) plus data the user's session verified live (the real takeUforward YouTube playlist, matched per-problem by text similarity; the real Blind 75 list scraped from neetcode.io, not a slice of NC150).
- Per-problem external links only (LeetCode, GfG, Code360, YouTube, NeetCode's own video page) — no embedded/scraped third-party prose or code solutions in this pass, for licensing reasons confirmed with the user. Original short topic notes are hand-written for this product.
- Progress, notes, bookmarks, and a solve-streak log persist in localStorage only, with export/import as a JSON file. No accounts, no login, no backend.
- Must render correctly and be fully usable on both mobile and desktop.
- Both a light and a dark theme are required, not dark-mode-only.

## Brand Commitments

- Name: **Pace**.
- Logo assets supplied by the user: a wordmark ("PACE", condensed geometric sans, road/speed-notch styling on the A) and a standalone mark (an orange/grey stylized "C" / speedometer-like glyph, transparent background) — copied into `public/pace-mark.png`.
- Explicit anti-brief from the user: must not look like a generic AI-generated dashboard clone (stock icon fonts, unicode glyphs as icons, single flat dark theme, no real brand icons). Real brand icons (LeetCode, GfG, YouTube, etc.) are required, not text abbreviations or emoji.

## Evidence on Hand

- `data-pipeline/sources/` holds the live-verified source data this session collected directly from takeuforward.org, YouTube, and neetcode.io (playlist scrape, Blind 75 category scrape).
- `_source_algo/`, `_source_neetcode/`, `_source_nc250/` are third-party open-source reference repos used only as structured data sources (problem titles/difficulties/links), not as design or code references.
- No user testimonials, pricing, or case studies exist or should be fabricated — this is a free personal-use tool, not a marketed product with proof points.

## Product Principles

1. Every link on the page must be real and resolvable — no placeholder hrefs, no fabricated video IDs, no guessed problem slugs.
2. Progress tracking is the core loop, not a bolt-on: it should be visible and satisfying at every level (per-problem, per-topic, per-track, and in aggregate).
3. Free means free — no feature in this app should be gated behind a login or payment the way the original TUF experience gates notes and videos.
4. The four tracks share one coherent design system and interaction model; a user switching from A2Z to NeetCode 150 should feel like they're in the same app, not a different skin.
